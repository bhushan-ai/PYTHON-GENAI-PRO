Virtual Environment of python is created using the command

****  ALWAYS WORK IN VENV

1. Traditional way to use the python

> first go to the directory in which u want create virtual env 
> python -m venv environment_name (example .venv) 
> Command for activation of venv: .venv\Scripts\activate

*** Install Third Party Modules in venv
>command: pip install <package name> (ex. pip install flask)

*** Another method
create the file named requirements
> write the package name one by one 
> ex. flask==2.31.0
> requests=3.0.0
>  run this command on venv to install these: pip install -r requirements.txt  

*** Deactivate
> command: deactivate
